# Hanny Kumar Portfolio

A responsive, single-page portfolio website created from the supplied resume.

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages (free)
1. Create or sign in to a GitHub account.
2. Create a new **public** repository named `hanny-portfolio`.
3. Upload `index.html` to the repository root and commit the change.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the deployment and copy the URL shown on the Pages settings page. It will usually look like `https://YOUR-USERNAME.github.io/hanny-portfolio/`.

## Before publishing
- Check that you want your phone number and email visible publicly.
- Replace the LinkedIn and GitHub placeholder links with your actual profile URLs.
- Add real project repository/demo links when available.
